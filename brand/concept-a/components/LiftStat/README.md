A tile showing one self-reported lift (bench press, squat, deadlift or overhead press) in kg with the lb value beneath.

**The consumer provides** the lift name, the weight stored in kg, and the lb value converted from it. Show both units, kg first. Lifts are optional, so leave out any tile that has no value rather than showing a zero or a dash.

- Label in `eyebrow` (uppercase), kg in `stat`, lb in `body-s` `ink-muted`.
- Tile: `surface` on a `surface-raised` card, 1px `line`, `radius-md`, `space-4` padding.
- Lay the tiles out two across; a single lift stays tile-width, never stretched.

**Don't** add rank, percentile or "personal best" claims. Lifts are self-reported and nothing verifies them.
